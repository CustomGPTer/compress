# Compress

Compress is a free, open-source Android app that makes phone videos smaller without a difference you can see. Quality levels or a size to fit, HEVC, H.264 and AV1, screen off. No adverts, no uploads.

Website: https://customgpter.github.io/compress/

Download: https://github.com/CustomGPTer/compress/releases/latest/download/Compress.apk
